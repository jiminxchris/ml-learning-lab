| 업종 구성 | 비율 변환·KMeans | 6개 가상 지역, 실제 상권 수익 평가가 아님 |

| HTTP·API | 준비한 응답·페이지·테이블 구조 | 실시간 API 서비스가 아님. 실제 요청은 Python에서 실행 |
| 아파트 누출 | 동일 분할의 OLS·기준 RMSE | 가상 자료; 금액을 X로 넣는 잘못된 사례와 비교 |

## 점수 해석

- 회귀의 학습·테스트는 동일 분할로 비교합니다. 브라우저에서 반복 실험하는 테스트는 학습용 관찰이며 실제 최종 평가의 독립성을 대신하지 않습니다.
- R²는 음수가 될 수 있습니다. 상수 정답의 경우 R²를 계산 불가로 표시합니다.
- 분류 지표는 분모 0일 때 0으로 처리합니다. macro F1은 클래스별 F1의 평균이며 macro precision·recall의 조화평균을 다시 구한 값이 아닙니다.
- 군집 번호는 임의의 이름입니다. 색이나 번호를 품종·순위와 직접 동일시하지 않습니다.
- PCA는 정답을 이용하지 않고 분산을 설명합니다. 설명분산비는 예측 정확도가 아닙니다.
- 원본 공간과 표준화 공간의 관성·eps·실루엣을 동일 기준으로 혼합하지 않습니다.

## 검증한 항목

수학·콘텐츠 11개 자동 검증에는 알려진 직선, 표준화, 규제 수축, 불균형 분류, KNN·트리·로지스틱, KMeans 중심, Ward 병합 높이, DBSCAN 경계·잡음, 손계산 실루엣, sklearn Iris PCA 비율, 25단원·75퀴즈의 참조 일관성을 포함합니다.

Chrome 검증은 각 25개 단원의 네 탭 100화면과 모바일 25개 실험, 슬라이더 범위 변경, 오답 기록, 재도전, 완료 상태, 관찰 노트 새로고침 유지, 기록 다운로드, CSS 문법 오류, 정적/동적 DOM 비교를 포함합니다. 마지막 수정 뒤 로컬과 게시 주소에서 확인합니다.

Python 3.13.15·scikit-learn 1.9.1에서 오프라인 23개 예제를 독립 실행했습니다. 웹 크롤링 2개 예제는 외부 네트워크·Chrome을 쓰는 별도 검증으로 구분합니다. 고정 출력은 실시간 브라우저 실험의 출력이 아니라 표시된 Python 예제의 실행 기록입니다.
